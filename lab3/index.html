01 Basics: Constructor & Overloading

Assignment-এর সব task দুইটা idea-র উপর: Constructor (overloading সহ) আর Method Overloading। আগে এগুলো পরিষ্কার করে নিই, তারপর tracing-এর কিছু ফাঁদ (trap) দেখব, যেগুলো exam-এ বারবার আসে।

1. Constructor কী?

Constructor একটা special method, যেটা new দিয়ে object তৈরি করার মুহূর্তে automatically call হয়। এর কাজ object-এর field গুলোতে শুরুর value বসানো (initialize করা)।

📏 Rules

  • নাম হুবহু class-এর নামের মতো হবে।
  • কোনো return type নেই, void-ও লেখা যাবে না।
  • নিজে আলাদা করে call করা যায় না, new লিখলেই চলে।
  • Constructor body চলার আগে field-এর initial value (যেমন int z = 5;) বসে যায়।
Example
public class Toy {
    public String name;
    public int price;

    public Toy(String name, int price) {   // constructor
        this.name = name;
        this.price = price;
        System.out.println("A new toy has been made!");
    }
}
// main-এ:
Toy t1 = new Toy("Car", 230);  // constructor auto call

2. Default constructor vs Parameterized constructor

Default constructor: তুমি class-এ একটাও constructor না লিখলে Java নিজে থেকে একটা খালি no-argument constructor দিয়ে দেয়। তখন field গুলো default value পায়।

TypeDefault value
int, long0
double0.0
booleanfalse
String / any object / arraynull

⚠️ Important: তুমি যদি কোনো একটা parameterized constructor লেখো, Java আর default constructor দেয় না। তখন new Toy() লিখলে compile error হবে। দুটোই লাগলে no-arg constructor-টাও নিজে লিখতে হবে।

HW Task 5-এর class A-তে কোনো constructor নেই, তাই default constructor চলে, আর x, y = 0।

3. Constructor Overloading

একই class-এ একাধিক constructor, প্রত্যেকটার parameter list আলাদা। new-এর সাথে যে argument দেবে, Java সেটা দেখে ঠিক constructor বেছে নেয়।

Example (Classwork Task 2, Task 4-এর মতো)
public class TaxiLagbe {
    public String number, area;

    public TaxiLagbe(String number, String area) {   // version 1
        this.number = number;
        this.area = area;
    }
    public TaxiLagbe(String number) {                // version 2
        this(number, "Khulna");   // constructor chaining → version 1 call
    }
}
new TaxiLagbe("1010-01", "Dhaka");  // → version 1
new TaxiLagbe("1010-02");           // → version 2 → area = "Khulna"

this(...) দিয়ে এক constructor থেকে আরেকটা call করা যায় (constructor chaining)। এটা সবসময় constructor-এর প্রথম statement হতে হবে।

4. this keyword আর Shadowing (tracing-এর জন্য সবচেয়ে জরুরি!)

Method বা constructor-এর ভেতরে যদি কোনো local variable বা parameter-এর নাম field-এর নামের সাথে মিলে যায়, তাহলে শুধু নাম লিখলে local/parameter-টা বোঝায়। একে shadowing বলে। Field বোঝাতে হলে this.name লিখতে হবে।

public class A {
    public int y = 4, sum = 9;

    public A(int y, int temp) {
        y = temp - 1;     // parameter y বদলায়, field না!
        sum = temp + 2;   // local sum নেই → field sum
        this.y = 100;     // field y বদলায়
    }
}
লেখাকোনটা বদলায়?
y = ... (local/param y আছে)local/parameter
y = ... (local y নেই)field (this.y)
this.y = ...সবসময় field

🔎 Tracing tip: প্রতিটা method শুরুর আগে লিখে রাখো এই method-এ কোন কোন নাম local (parameter + ভেতরে declare করা)। বাকি সব নাম field।

5. Method Overloading

একই class-এ একই নামের একাধিক method, কিন্তু parameter list আলাদা। Parameter list আলাদা হতে পারে ৩ ভাবে:

① সংখ্যা
add(int a, int b)
add(int a, int b, int c)
② Type
setParameters(String, int, int)
setParameters(String, double, double)
③ Order
addItem(String, double)
addItem(double, String)
এগুলো overloading না (compile error)কেন?
int f(int a) আর void f(int a)শুধু return type আলাদা হলে চলবে না
f(int a) আর f(int b)শুধু parameter-এর নাম আলাদা, type একই

Signature = method-এর নাম + parameter-এর type গুলোর list (order সহ)। Return type signature-এর অংশ না।

6. Java কীভাবে ঠিক করে কোন version call হবে?

Compile time-এ Java call-এর argument গুলোর type আর সংখ্যা দেখে, তারপর যে method-এর parameter list মেলে সেটা বেছে নেয়।

circle.setParameters("Circle", 5);            // (String, int)          → circle
triangle.setParameters("Triangle", 4, 7);     // (String, int, int)     → triangle
rectangle.setParameters("Rectangle", 2.4, 4.4); // (String, double, double) → rectangle

a1.methodB(1, x);        // x হলো int[] → methodB(int, int[])
this.methodB(x, m);      // দুইটাই int  → methodB(int, int)
c1.giveDiscount(10);     // parameter double হলে int → double auto widening (10 → 10.0)

7. Tracing cheat-sheet: যে ফাঁদগুলোয় সবাই পড়ে

🔢 x++ vs ++x

x++: আগে পুরনো value ব্যবহার, পরে বাড়ে। ++x: আগে বাড়ে, পরে ব্যবহার।
methodB(x++, …) with x=2 → 2 pass হয়, পরে x = 3।

➡️ বাম থেকে ডানে evaluation

y = y + m + call(): call হওয়ার আগেই y-এর পুরনো value পড়া হয়ে যায়। call-এর ভেতরে y বদলালেও সেটা overwrite হয়ে যাবে।
arr[0] += call(): arr[0]-এর পুরনো value আগে পড়া হয়।

🧵 String concatenation

একবার String চলে আসলে পরের + সব জোড়া লাগানো:
11 + " " + 3 + 11 → "11 311"
কিন্তু x + " " + (m + this.x) → bracket-এর ভেতরে আগে যোগ।

➗ Integer division ও precedence

10 / 3 = 3, 7 / 2 = 3 (int হলে দশমিক কেটে যায়)।
*, /, % আগে, +, - পরে: 2 + 11 % 3 * 3.0 = 2 + 2*3.0 = 8.0

📦 Primitive vs Array argument

int/double parameter হলো copy, method-এ বদলালে caller-এর variable বদলায় না।
Array/object পাঠালে reference যায়, n[0] = … করলে main-এর array-ও বদলায়!

🧱 প্রতি call-এ নতুন frame

Method-এর local variable আর local array (int arr[] = {3,4,5}) প্রতিবার call-এ নতুন করে তৈরি হয়। আগের call-এর value থাকে না।

🗑 Return value ignore

methodB(m);: return করা value কোথাও রাখা না হলে সেটা হারিয়ে যায়, কিন্তু method-এর ভেতরের print আর field change ঠিকই হয়।

🏗 Constructor-ও print করে

new Maze() লিখলেই constructor চলে। ভেতরে method call/print থাকলে সেটা output-এ আসবে। new Maze().methodB(7,15) → আগে constructor, তারপর method।

📝 Exam-এ trace করার নিয়ম: (1) প্রতিটা object-এর জন্য একটা box বানাও, field গুলো লিখে রাখো। (2) প্রতিটা method call-এ আলাদা box (frame) বানাও, local গুলো সেখানে লেখো। (3) প্রতিটা line-এ কোন variable বদলালো কেটে নতুন value লেখো। (4) print হলে output table-এ এক row-তে লেখো।

Task 1 — Shape (method overloading)

❓ Question

Driver code-এর output মিলিয়ে Shape class design করতে হবে। একই setParameters() method ৩ ভাবে call হচ্ছে: circle (radius), triangle (base, height), rectangle (length, width)।

Driver code (দেওয়া আছে, change করা যাবে না)
ShapeTester.java
public class ShapeTester{
  public static void main(String args []){
    Shape circle = new Shape();
    Shape triangle = new Shape();
    Shape rectangle = new Shape();
    circle.setParameters("Circle", 5);
    triangle.setParameters("Triangle", 4, 7);
    rectangle.setParameters("Rectangle", 2.4, 4.4);
    System.out.println(circle.details());
    System.out.println("1---------------");
    System.out.println(triangle.details());
    System.out.println("2---------------");
    System.out.println(rectangle.details());
  }
}
💡 হালকা explanation
  • setParameters কে ৩ বার overload করেছি: (String, int), (String, int, int), (String, double, double)।
  • Java argument-এর সংখ্যা আর type দেখে ঠিক করে কোনটা call হবে: ("Triangle", 4, 7) → দুইটা int → triangle version; ("Rectangle", 2.4, 4.4) → দুইটা double → rectangle version।
  • Area: circle = πr², triangle = ½ × base × height, rectangle = length × width।
  • Output-এ দুই decimal দরকার, তাই String.format("%.2f", area)। details() একটা String return করে, print করে না, কারণ driver নিজে println করছে।
✅ Solution
Shape.java
public class Shape {
    public String name;
    public double area;

    // Circle: name + radius
    public void setParameters(String name, int radius) {
        this.name = name;
        this.area = Math.PI * radius * radius;
    }

    // Triangle: name + base + height (int, int)
    public void setParameters(String name, int base, int height) {
        this.name = name;
        this.area = 0.5 * base * height;
    }

    // Rectangle: name + length + width (double, double)
    public void setParameters(String name, double length, double width) {
        this.name = name;
        this.area = length * width;
    }

    public String details() {
        return "Shape Name: " + name + "\nArea: " + String.format("%.2f", area);
    }
}
Output (driver চালিয়ে verify করা)
Shape Name: Circle
Area: 78.54
1---------------
Shape Name: Triangle
Area: 14.00
2---------------
Shape Name: Rectangle
Area: 10.56

Task 2 — Shape2D (constructor overloading)

❓ Question

Shape2D class এমনভাবে design করো যাতে ৪ রকম ভাবে object বানানো যায়: argument ছাড়া (square), ২টা int (rectangle), ২টা int + String (triangle with height/base), ৩টা int (triangle with 3 sides)।

Driver code (দেওয়া আছে, change করা যাবে না)
Shape2DTester.java
public class Shape2DTester {
  public static void main(String[] args) {
    Shape2D sq = new Shape2D();
    System.out.println("---------1----------");
    sq.area();
    System.out.println("---------2----------");
    Shape2D rectangle = new Shape2D(5, 6);
    System.out.println("---------3----------");
    rectangle.area();
    System.out.println("---------4----------");
    Shape2D tri1 = new Shape2D(5, 6, "Triangle");
    System.out.println("---------5----------");
    tri1.area();
    System.out.println("---------6----------");
    Shape2D tri2 = new Shape2D(5, 6, 7);
    System.out.println("---------7----------");
    tri2.area();
  }
}
💡 হালকা explanation
  • এখানে ৪টা constructor, প্রত্যেকটার parameter list আলাদা, এটাই constructor overloading।
  • (int, int, String) আর (int, int, int) দুইটাতেই ৩টা parameter, কিন্তু ৩য়টার type আলাদা, তাই valid overloading।
  • প্রতিটা constructor একটা type field-এ মনে রাখে কোন shape বানানো হলো; পরে area() সেটা দেখে formula বেছে নেয়।
  • ৩ বাহু দিয়ে triangle-এর area-র জন্য Heron's formula: s = (a+b+c)/2, area = √(s(s−a)(s−b)(s−c)) → 5,6,7 এর জন্য 14.70।
✅ Solution
Shape2D.java
public class Shape2D {
    public String type;
    public int a, b, c;

    // No argument -> Square of length 5
    public Shape2D() {
        type = "Square";
        a = 5;
        System.out.println("A Square has been created with length: " + a);
    }

    // Two ints -> Rectangle
    public Shape2D(int length, int breadth) {
        type = "Rectangle";
        a = length;
        b = breadth;
        System.out.println("A Rectangle has been created with length: " + a + " and breadth: " + b);
    }

    // Two ints + String -> Triangle with height & base
    public Shape2D(int height, int base, String name) {
        type = name;   // "Triangle"
        a = height;
        b = base;
        System.out.println("A Triangle has been created with height: " + a + " and base: " + b);
    }

    // Three ints -> Triangle with three sides
    public Shape2D(int s1, int s2, int s3) {
        type = "TriangleSides";
        a = s1;
        b = s2;
        c = s3;
        System.out.println("A Triangle has been created with the following sides: " + a + ", " + b + ", " + c);
    }

    public void area() {
        double result;
        String name;
        if (type.equals("Square")) {
            result = a * a;
            name = "Square";
        } else if (type.equals("Rectangle")) {
            result = a * b;
            name = "Rectangle";
        } else if (type.equals("Triangle")) {
            result = 0.5 * a * b;
            name = "Triangle";
        } else {                       // Heron's formula
            double s = (a + b + c) / 2.0;
            result = Math.sqrt(s * (s - a) * (s - b) * (s - c));
            name = "Triangle";
        }
        System.out.println("The area of the " + name + " is: " + String.format("%.2f", result));
    }
}

---------2----------
A Rectangle has been created with length: 5 and breadth: 6
---------3----------
The area of the Rectangle is: 30.00
---------4----------

---------5----------
The area of the Triangle is: 15.00

✅ Solution
Library.java
public class Library {
    public int capacity;
    public String[] books;
    public int count = 0;

    public Library(int capacity) {
        this.capacity = capacity;
        this.books = new String[capacity];
        System.out.println("A library has been created with capacity " + capacity);
    }

    public void addBook(String name) {
        if (count < capacity) {
            books[count] = name;
            count++;
            System.out.println("Book '" + name + "' added to the library");
        } else {
            System.out.println("Exceeds maximum capacity. You can't add more than " + capacity + " books");
        }
    }

    public void printDetail() {
        System.out.println("Maximum Capacity: " + capacity);
        System.out.println("Total Books: " + count);
        System.out.println("Book list:");
        for (int i = 0; i < count; i++) {
            System.out.println(books[i]);
        }
    }
}

public class Cart {
    public int cartNumber;
    public String[] items = new String[3];
    public double[] prices = new double[3];
    public int count = 0;
    public double discount = 0.0;

    public void create_cart(int number) {
        cartNumber = number;
    }

    // (String, double)
    public void addItem(String item, double price) {
        if (count < 3) {
            items[count] = item;
            prices[count] = price;
            count++;
            System.out.println(item + " added to cart " + cartNumber + ".");
            System.out.println("You have " + count + " item(s) in your cart now.");
        } else {
            System.out.println("You already have 3 items on your cart");
        }
    }

    // (double, String) -> parameter order alada, tai eta-o overloading
    public void addItem(double price, String item) {
        addItem(item, price);
    }

    public void giveDiscount(double percent) {
        discount = percent;
    }

    public void cartDetails() {
        System.out.println("Your cart(c" + cartNumber + ") :");
        double total = 0;
        for (int i = 0; i < count; i++) {
            System.out.println(items[i] + " - " + prices[i]);
            total += prices[i];
        }
        total = total - total * discount / 100;
        System.out.println("Discount Applied: " + discount + "%");
        System.out.println("Total price: " + total);
    }
}

        books = new String[capacity];

        this.name = name;
        this.capacity = capacity;
        books = new String[capacity];
        System.out.println("A new reader is created!");
    }

        if (count < capacity) {
            books[count] = book;
            count++;
        } else {
            System.out.println("No more capacity");
        }

        for (int i = 0; i < count; i++) {
            newBooks[i] = books[i];       // purono book copy
        }
        books = newBooks;
        capacity = newCapacity;
        System.out.println("Capacity has changed to " + capacity);
    }
}

public class MoneyTracker {
    public String name;
    public double balance;
    public double lastAdded;
    public double lastSpent;

    public MoneyTracker() {
        System.out.println("A new money tracker has been launched.");
    }

    public void createTracker(String name) {
        this.name = name;
        balance = 1.0;
    }

    public String info() {
        return "Name: " + name + "\nCurrent Balance: " + balance;
    }

    public void income(double amount) {
        balance += amount;
        lastAdded = amount;
        System.out.println("Balance Updated!");
    }

    public void expense(double amount) {
        if (amount > balance) {
            System.out.println("Not enough balance.");
        } else {
            balance -= amount;
            lastSpent = amount;
            if (balance == 0) {
                System.out.println("You're broke!");
            } else {
                System.out.println("Balance Updated.");
            }
        }
    }

    public void showHistory() {
        System.out.println("Last added: " + lastAdded);
        System.out.println("Last spent: " + lastSpent);
    }
}

Customer.java
public class Customer {
    public String name;
    public String[] items = new String[4];
    public int[] prices = new int[4];
    public int count = 0;

    public void createCustomer(String name) {
        this.name = name;
    }

    // price na dile default 3
    public void addItem(String item) {
        addItem(item, 3);
    }

    public void addItem(String item, int price) {
        if (count < 4) {
            items[count] = item;
            prices[count] = price;
            count++;
            System.out.println(item + " added to cart");
        } else {
            System.out.println("Cart is full");
        }
    }

    public void addItem(String item1, int price1, String item2, int price2) {
        if (count + 2 <= 4) {
            items[count] = item1;  prices[count] = price1;  count++;
            items[count] = item2;  prices[count] = price2;  count++;
            System.out.println(item1 + " and " + item2 + " added to cart");
        } else {
            System.out.println("Cart is full");
        }
    }

    public void showCart() {
        System.out.println("Customer: " + name);
        for (int i = 0; i < count; i++) {
            System.out.println("Item: " + items[i] + " Price: " + prices[i]);
        }
    }

    public void calculatePrice() {
        int total = 0;
        for (int i = 0; i < count; i++) total += prices[i];
        System.out.println("Total: " + total);
    }
}

        System.out.println(a + b);
    }

public class Movie {

        this.director = director;

        for (int i = 0; i < count; i++) {
            if (i > 0) list += ", ";
            list += actors[i];
        }
        System.out.println("Actors: " + list);
    }
