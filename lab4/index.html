01 Basics: Reference Passing & Multi-class

এই lab-এর দুইটা মূল idea: Reference Passing (object বা array method-এ পাঠালে আসলে কী যায়) আর Multi-class problem (একাধিক class একসাথে কাজ করে, এক class-এর ভেতরে আরেক class-এর object থাকে)। এগুলো পরিষ্কার হলে tracing-ও সহজ হয়ে যাবে।

1. Primitive variable vs Reference variable

Primitive (int, double, char, boolean): variable-এর ভেতরে সরাসরি value থাকে।

Reference (যেকোনো object, array, String): variable-এর ভেতরে object থাকে না, থাকে object-এর address (reference)। Object নিজে থাকে heap-এ।

🔎 ভাবো এভাবে: reference variable হলো একটা remote control, আর object হলো TV। দুইটা remote একই TV control করতে পারে।

Example
int a = 5;
int b = a;      // value copy
b = 10;         // a এখনো 5

Triangle t1 = new Triangle(4, 4, 4);
Triangle t2 = t1;   // address copy → একই object!
t2.a = 9;           // t1.a-ও এখন 9

2. Object assignment আর ==

  • t1 = t2;: নতুন object তৈরি হয় না, t1 এখন t2-এর object-টাকেই point করে। t1-এর পুরনো object-এর কাছে আর কেউ না থাকলে সেটা garbage হয়ে যায়।
  • t1 == t2: address compare করে, মানে দুইটা কি একই object? Field গুলোর value এক হলেও আলাদা object হলে false।
  • Field দিয়ে compare করতে হলে নিজে করতে হবে: a == other.a && b == other.b ...
  • String compare-এ == না, .equals() ব্যবহার করো (CW Task 2, UG Task 1)।
Classwork Task 1 থেকে
Triangle t2 = new Triangle(4, 5, 6);
Triangle t3 = new Triangle(4, 5, 6);
t2 == t3     // false: আলাদা address, sides same
t1 = t2;
t1 == t2     // true: same address

4. কোন object-এর উপর method চলছে? (this বদলায়!)

t.methodB(2,3) লিখলে methodB-এর ভেতরে this = t। একই class-এর ভেতর থেকেও অন্য object-এর method call করা যায়, তখন field গুলো ওই object-এর।

public Trace(Trace t) {   // new Trace(t1)
    sum = t.sum++;   // this.sum (নতুন obj) = t1.sum; t1.sum++
    x = t.x + 2;
    t.methodB(2,3);  // methodB চলে t1-এর উপর!
}
  • শুধু x লিখলে = this.x = যে object-এর উপর method চলছে তার x।
  • t.x = parameter t যে object কে point করে তার x।
  • a2.methodC(this): methodC-এর ভেতরে this = a2, আর parameter a = আগের this (a1)। উল্টে যায়! (HW Task 6)

5. Multi-class problem: এক class-এর ভেতরে আরেক class-এর object

বাস্তবে একটা জিনিস আরেকটা জিনিসকে "ধরে রাখে" (has-a relationship): Teacher-এর কাছে Course আছে, Team-এ Player আছে, Connect-এর কাছে Student আছে। এজন্য একটা class-এ অন্য class-এর object-এর array রাখা হয়।

Classwork Task 3
public class Course {
    public String name;
    public Course(String name) { this.name = name; }
}

public class Teacher {

  • Array-তে object রাখলে আসলে reference রাখা হয়। পরে মূল object বদলালে array থেকেও বদলানো value দেখা যায় (HW Task 3: updateCost-এর পর itinerary-তে 610)।
  • Loop চালাও count পর্যন্ত, length পর্যন্ত না। নাহলে null.name → NullPointerException!
  • প্রতিটা class আলাদা .java file-এ রাখো (Course.java, Teacher.java)।

6. একই class-এর object parameter হিসেবে

একটা class-এর method নিজের class-এরই আরেকটা object নিতে পারে: compareTriangles(Triangle other), defeatVillain(Player other), addItem(Shop other, String item)। ভেতরে this = যে call করেছে, other = যাকে পাঠানো হয়েছে।

7. Tracing cheat-sheet (Lab 4)

📦 Heap-এ box আঁকো

প্রতিটা new-এর জন্য আলাদা box (object) আঁকো, নাম দাও (t1, t2, exam…)। Variable থেকে box-এ তীর দাও। দুইটা variable একই box-এ তীর দিলে একটা বদলালে দুইটাই বদলায়।

🎯 this কে?

obj.method() চললে method-এর ভেতরে this = obj। Field নাম একা লিখলে (sum) সেটা this-এর field, যদি একই নামে local/parameter না থাকে।

🔁 Reference parameter

x2.sum = … → x2 যে object-এ তীর দেয় সেটাই বদলায়, caller-এর variable (exam) দিয়েও সেটা দেখা যাবে।

➡️ বাম থেকে ডানে

this.y = this.sum + methodB(…): this.sum call-এর আগে পড়া হয়। methodB sum বদলালেও পুরনো value ব্যবহার হয়। … + methodC(…) + x: x পড়া হয় call-এর পরে!

🔢 x++ / ++x

sum = t.sum++ → পুরনো value assign, পরে t.sum বাড়ে। (sum++) print-এর ভেতরে থাকলে পুরনো value print হয়, পরে বাড়ে।

🧵 int + int + String

t1.y + t1.x + " " → প্রথম দুইটা int, তাই আগে যোগ (12+6 = 18)। String আসার পরে concatenation।

🏗 Constructor-এর ভেতরে call

new Trace(t1)-এর ভেতরে t.methodB() চললে সেটা t1-কে বদলায় আর print-ও করে, object তৈরির সময়েই।

🗂 প্রতিটা object-এর নিজের field

নতুন object (new TestX()) বানালে তার field আবার initial value থেকে শুরু: i = 0, result = 17, নিজের নতুন array। অন্য object-এর বদলানো value আসে না।

📝 Exam-এ trace করার নিয়ম: (1) প্রতিটা object-এর জন্য box, field লেখো। (2) প্রতিটা method call-এ আলাদা frame, উপরে লেখো this = কে। (3) Object parameter-এর জন্য লেখো "x2 → exam"। (4) প্রতি line-এ কোন box-এর কোন field বদলালো কেটে নতুন value লেখো। (5) Print হলে output table-এ এক row।

Triangle.java
public class Triangle {
    public int a, b, c;

    public Triangle(int a, int b, int c) {
        this.a = a;
        this.b = b;
        this.c = c;
    }

    public int perimeter() {
        return a + b + c;
    }

    public void triangleDetails() {
        System.out.println("Three sides of the triangle are: " + a + ", " + b + ", " + c);
        System.out.println("Perimeter: " + perimeter());
    }

    public String printTriangleType() {
        if (a == b && b == c) {
            return "This is an Equilateral Triangle.";
        } else if (a == b || b == c || a == c) {
            return "This is an Isosceles Triangle.";
        } else {
            return "This is a Scalene Triangle.";
        }
    }

    // অন্য একটা Triangle object এর reference parameter হিসেবে আসে
    public void compareTriangles(Triangle other) {
        if (this == other) {                       // একই address (same object)
            System.out.println("These two triangle objects have the same address.");
        } else if (a == other.a && b == other.b && c == other.c) {
            System.out.println("Addresses are different but the sides of the triangles are equal.");
        } else if (perimeter() == other.perimeter()) {
            System.out.println("Only the perimeter of both triangles is equal.");
        } else {
            System.out.println("Addresses, length of the sides and perimeter all are different.");
        }
    }
}

Shop.java
public class Shop {
    public String name;
    public int capacity;
    public String[] items;
    public int[] prices;
    public int count = 0;

    public Shop(String name, int capacity) {
        this.name = name;
        this.capacity = capacity;
        items = new String[capacity];
        prices = new int[capacity];
        System.out.println(name + " shop created!");
    }

    // নাম না দিলে default "Mega"
    public Shop(int capacity) {
        this("Mega", capacity);
    }

    public void addItem(String item, int price) {
        if (count < capacity) {
            items[count] = item;
            prices[count] = price;
            count++;
        } else {
            System.out.println(item + ", could not be added");
        }
    }

    // অন্য Shop object থেকে item খুঁজে এনে নিজের shop-এ add
    public void addItem(Shop other, String item) {
        for (int i = 0; i < other.count; i++) {
            if (other.items[i].equals(item)) {
                addItem(item, other.prices[i]);
                return;
            }
        }
        System.out.println(item + ", not found in " + other.name + "!");
    }

    public void purchase(String item) {
        for (int i = 0; i < count; i++) {
            if (items[i].equals(item)) {
                System.out.println("Purchase Complete!");
                return;
            }
        }
        System.out.println(item + ", is not available in this shop");
    }

    public void info() {
        System.out.println("Shop Name: " + name);
        System.out.println("Item Details:");
        if (count == 0) {
            System.out.println("No items in shop");
        } else {
            System.out.println(count + " / " + capacity);
            for (int i = 0; i < count; i++) {
                System.out.println(items[i] + " - " + prices[i] + " Tk");
            }
        }
    }
}

public class TravelPrep {

    public String t_name = "Unknown package";
    public int budget = 1250;
    public TravelPrep[] itinerary = new TravelPrep[3];
    public int count = 0;

    // ---- destination এর তথ্য ----
    public String d_name, d_type;
    public int cost;

    // 1) Package: default
    public TravelPrep() {
        System.out.println(t_name + " would cost at most " + budget + " yen");
    }

    // 2) Package: name + budget
    public TravelPrep(String t_name, int budget) {
        this.t_name = t_name;
        this.budget = budget;
        System.out.println(t_name + " would cost at most " + budget + " yen");
    }

    // 3) Destination: (name, type), default cost 300
    public TravelPrep(String d_name, String d_type) {
        this.d_name = d_name;
        this.d_type = d_type;
        this.cost = 300;
        System.out.println(d_name + " " + d_type + " costs " + cost + " yen");
    }

    // 4) Destination: (type, name, cost)  <- order খেয়াল করো
    public TravelPrep(String d_type, String d_name, int cost) {
        this.d_name = d_name;
        this.d_type = d_type;
        this.cost = cost;
        System.out.println(d_name + " " + d_type + " costs " + cost + " yen");
    }

    public int totalCost() {
        int total = 0;
        for (int i = 0; i < count; i++) total += itinerary[i].cost;
        return total;
    }

    public void add_to_itinerary(TravelPrep d) {
        if (count >= 3) {
            System.out.println("Maximum 3 destinations allowed");
        } else if (totalCost() + d.cost > budget) {
            System.out.println("Budget going overboard");
        } else {
            itinerary[count] = d;     // object এর reference store
            count++;
        }
    }

    public void add_to_itinerary(TravelPrep d1, TravelPrep d2) {
        add_to_itinerary(d1);
        add_to_itinerary(d2);
    }

    public String updateCost(int extra) {
        cost += extra;
        return "Cost of " + d_name + " " + d_type + " updated to " + cost;
    }

    public void show_itinerary() {
        System.out.println("Itinerary for " + t_name);
        for (int i = 0; i < count; i++) {
            TravelPrep d = itinerary[i];
            System.out.println((i + 1) + ". " + d.d_name + " " + d.d_type + " - " + d.cost + " yen");
        }
        System.out.println("Total cost of " + count + " destinations: " + totalCost() + " yen");
    }
}

public class ConnectFriends {
    public String name;
    public int limit;
    public ConnectFriends[] sent;
    public int count = 0;

    public ConnectFriends(String name, int limit) {
        this.name = name;
        this.limit = limit;
        sent = new ConnectFriends[limit];
        System.out.println("Welcome to ConnectFriends, " + name);
    }

    public ConnectFriends(String name) {
        this(name, 2);
    }

    public void sendFriendRequest(ConnectFriends f) {
        if (count < limit) {
            sent[count] = f;
            count++;
            System.out.println(name + " sent a friend request to " + f.name + ".");
        } else {
            System.out.println(name + " has reached the friend request limit!");
        }
    }

    public void sendFriendRequest(ConnectFriends f1, ConnectFriends f2) {
        sendFriendRequest(f1);
        sendFriendRequest(f2);
    }

    public void removeRequest(String friend) {
        for (int i = 0; i < count; i++) {
            if (sent[i].name.equals(friend)) {
                for (int j = i; j < count - 1; j++) sent[j] = sent[j + 1];   // shift left
                sent[count - 1] = null;
                count--;
                System.out.println("Reuqest to add " + friend + " is removed for " + name + ".");
                return;
            }
        }
        System.out.println(friend + " is not in " + name + "'s sent request list.");
    }

    public void showDetails() {
        System.out.println("User Name: " + name);
        System.out.println("Maximum number of Sent Friend Request: " + limit);
        System.out.println("Total Friends Request: " + count);
        String list = "Sent Friends Request:";
        for (int i = 0; i < count; i++) list += " " + sent[i].name;
        System.out.println(list);
    }
}

public class Cart {
    public String[] names = new String[10];
    public int[] prices = new int[10];
    public int count = 0;
    public Cart[] carts = new Cart[3];
    public int cartCount = 0;

        names[count] = name;
        prices[count] = price;
        count++;
    }

        storeProduct(n1, p1);
        storeProduct(n2, p2);

        System.out.println("Cart Items:");
        if (count == 0) {
            System.out.println("The cart is empty.");
        }
        for (int i = 0; i < count; i++) {
            System.out.println(names[i] + " - " + prices[i]);
        }

    public void transferItem(Cart other, String name) {
        for (int i = 0; i < count; i++) {
            if (names[i].equals(name)) {

                for (int j = i; j < count - 1; j++) {
                    names[j] = names[j + 1];
                    prices[j] = prices[j + 1];
                }
                count--;

                return;

        carts[1] = b;
        carts[2] = c;
        cartCount = 3;
    }

    public void allCartInfo() {

            carts[i].info();
        }
